# 桌面壳热键与快捷键对照表

> 第二百零五轮①：全局热键（桌面壳注册，OS 级）与启动器 UI 快捷键（浏览器级）分层互不干扰。
> 审计原则：全局热键必须带 OS 级修饰键（Alt/Ctrl+Alt），永不占用浏览器级组合（Ctrl+字母）。

## 全局热键（OS 级，桌面壳注册）

| 热键 | 行为 | 冲突风险 |
|------|------|---------|
| Alt+Space（默认首选） | 显示/隐藏主窗口 | macOS 需在系统设置中处理输入法冲突（候选顺序自动降级） |
| Ctrl+Alt+Space（备选） | 同上 | 低 |
| Alt+Z（末选） | 同上 | 低 |
| 自定义（boot_config.hotkey） | 同上 | 用户自担——parse_hotkey 支持修饰键+字母/Space |

规则：全局热键候选全部带 Alt 系修饰键，永不注册裸字母或 Ctrl+字母（会抢浏览器/UI 快捷键）。

## 启动器 UI 快捷键（浏览器级，只在窗口聚焦时生效）

| 快捷键 | 行为 |
|--------|------|
| Ctrl+P / Ctrl+K | 命令面板 |
| Ctrl+L | 审计日志 |
| Ctrl+Shift+D | 深浅色切换 |
| Ctrl+/ | 快捷键速查 |
| 1-9（面板内） | 直选第 N 项 |
| ↑↓/Enter/Esc/Tab | 面板与搜索共用导航语言 |
| j/k | 结果表行选择 |
| x / m / e / y | 结果导出/复制系列 |
| [ / ] | 结果页签切换 |
| Ctrl+. | 停止执行中的动作 |
| F 收藏 / T 标签 / ? 速查 | 列表与全局 |

## 分层原则

- 全局热键在 OS 层拦截（窗口未聚焦也生效）——必须稀有（Alt+Space 系）
- UI 快捷键只在窗口聚焦时生效——可以用 Ctrl+字母（不与系统冲突）
- 两层永不交叉：全局候选表不进 UI 快捷键表，反之亦然
- 托盘菜单是第三入口（鼠标），与两层键盘互补

## doctor desktop 字段

`zkit doctor --json` 的 `desktop` 字段报：installed / path / hotkey / deepLinkRegistered——
桌面壳与内核版本一致性由 release-prep 五处同步保证（壳号即内核号）。
