01启动器主界面

搜索一切动作、四模式切换、顶栏直达各面板——所有截图均为真实运行状态（14 个插件 61 个动作已装载）。

01命令模式首页 主入口

顶栏常驻：插件计数、NetBar 仪表盘、运行中进程、集市入口、设置抽屉；中栏是全部动作的可搜索列表，支持拼音/别名匹配。

02即时搜索过滤

输入 sysinfo 即时过滤——动作名、插件名、标签多路匹配，无回车等待。

10设置抽屉

主题、语言、最近活动、日志、全景总检、缓存、自检、收藏、定时、简报、监控、插件配置、分享包导入——一抽屉全收纳，带搜索。

27书签管理 #/bookmarks

钉住常用动作直达，与 CLI bookmarks.json 同源——两边改互相同步。

02执行与结果

从搜索到参数表单到执行结果——每一步都有真实数据（截图中的执行记录为真实运行产生）。

03动作详情与参数表单

点开动作即见风险级别、参数 JSON Schema 生成的表单、默认值与说明——不知道填什么就照提示来。

04执行结果面板

真实执行 convert.b64 的输出——结构化结果分层渲染，耗时/状态一目了然，可收藏、可重放。

12时间线与执行复盘 #/timeline

历史执行按时间轴排开，成功/失败分色——失败的可一键重放参数。

11最近活动 #/activity

执行健康时间线：每次执行、被拒、失败都记着——审计视图。

03插件体系

manifest 驱动——一份 plugin.toml 摊开成四个面。装/卸/升级/自检/导出全在界面里。

05插件管理 #/plugins

来源、版本、动作数、风险组合（读/写/危险三色）一屏看全；安装/更新/卸载带确认清单。

06插件主页 #/plugins/<id>

单插件全动作视图：每个动作的风险、参数、示例命令；可直达执行。

20插件配置向导 #/config

缺什么配置一目了然——逐项填写、密钥项打码、来源标注（默认/环境/用户覆盖）。

15环境自检 #/doctor

解释器、插件依赖、必填配置逐项体检——问题不只报错还带修复指引。

04集市

装插件不用记地址——浏览、搜索、一键安装（安装前先摊开它的全部能力让你确认）。

09集市浏览 #/market

多集市源聚合：插件卡片带风险组合预览；添加集市 = 一个 git 仓库地址。

05观测与运维

跑起来之后的一切可观测面：仪表盘、进程、服务、缓存、日志、简报、监控、性能。

07NetBar 仪表盘 #/dashboard

收藏、最近执行、监控、今日统计一屏看全——数据全在本机。

08运行中 #/ps

托管的进程 + 插件声明的服务实时列表——与 CLI zkit ps 同源。

13服务面板 #/services

插件声明的长驻服务：状态、端口、日志尾巴——起停都在界面里。

14缓存面板 #/cache

只读动作的缓存：条目数、命中率——同参数不重复跑。

21审计日志 #/logs

每次执行、被拒、失败全记录；三档筛选、密钥自动打码、可导出。

18今日简报 #/brief

跑了多少、成败比、最常用动作——一天的工作量一页说清。

19监控面板 #/watch

盯着的动作都在这：监控中的条目、最近输出、停止入口。

17定时任务 #/timers

界面开着才跑的自动执行：间隔、执行窗口（09:00-18:00）、暂停/恢复——落盘后 CLI 侧同源。

24性能面板 #/perf

体感问题的量化入口：搜索延迟、执行耗时分布——慢不慢用数据说话。

16收藏结果 #/saved

钉住重要的输出——跨会话留存，与时间线互相跳转。

06MCP / AI 对接

22MCP 工具清单 #/mcp

23MCP 授权管理

副作用动作默认禁用——逐项授权给 AI（写/危险级需显式放行），授权留痕。

07高级面板

进阶能力：剪贴板、协作、开发者、帮助、命令面板。

28剪贴板历史 #/clip

29协作面板 #/collab

会话协作：广播过滤、在场状态——多客户端协同的调试台。

26开发者面板 #/dev

插件开发者的内窥镜：清单解析、注入面、路由表核对——开发期排查用。

25帮助页 #/help

HELP_TOPICS 逐段讲解，每段带「去试用」深链——新用户上手路径。

08CLI 命令行

八个分节：基本 / 配置 / 插件 / 执行与历史 / 观测 / MCP 与 AI / 桌面 / 运维——zkit man 看逐条参考。

35集市搜索 zkit market search

命令行逛集市：关键词过滤、版本与风险组合——安装走 plugin install。

36MCP 接入配置 zkit mcp config

各家 AI 客户端的接入片段一键打印/写入——Claude / Cursor 等开箱即接。

37插件流水 zkit plugin history

安装/升级/卸载全记录——供应链变化的审计线索。

09安全模型（贯穿全部界面）

不是单独页面，而是每个动作身上的三色标签：绿色只读、黄色写、红色危险——写/危险级在 AI 侧默认禁用，界面侧显式确认。

风险组合标注——每个插件的 read / mutate / destructive 数量

manifest 声明风险级别 → 界面/CLI/MCP 三处同构展示 → 副作用动作默认拒绝。这是 552 轮迭代沉淀下来的信任模型：能力透明、授权显式、全程留痕。
